# Building Markdown Notes (React Native / Expo)

Requirements: macOS with Xcode 26+, Node.js 22+, CocoaPods (installed with Xcode tooling / `gem install cocoapods`).
All commands run from this `react-native/` directory and are non-interactive. The `ios/` folder is
generated by Expo prebuild (Continuous Native Generation) and is not committed.

The Release builds embed the JS bundle (`main.jsbundle`) in the `.app`; no Metro/dev server is needed.

## a) Install dependencies

```sh
npm ci
CI=1 npx expo prebuild --platform ios --clean   # generates ios/ and runs `pod install`
```

## b) Release `.app` for the iOS Simulator

```sh
xcodebuild -workspace ios/MarkdownNotes.xcworkspace -scheme MarkdownNotes \
  -configuration Release -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath ios/build/sim build -quiet
echo "$PWD/ios/build/sim/Build/Products/Release-iphonesimulator/MarkdownNotes.app"
```

Install/run (optional): `xcrun simctl install <UDID> <path above> && xcrun simctl launch <UDID> com.mdnotes.reactnative`

## c) Release `.app` for a generic iOS device (no code signing)

```sh
xcodebuild -workspace ios/MarkdownNotes.xcworkspace -scheme MarkdownNotes \
  -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' \
  -derivedDataPath ios/build/device CODE_SIGNING_ALLOWED=NO build -quiet
echo "$PWD/ios/build/device/Build/Products/Release-iphoneos/MarkdownNotes.app"
```
